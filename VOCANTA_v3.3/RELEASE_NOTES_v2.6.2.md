# VOCANTA v2.6.2

## Permanent Applicant Profile

Applicant data now lives at `%LOCALAPPDATA%\VOCANTA\applicant_profile.json`, outside version folders.

- Existing profiles are imported automatically when found.
- If none exists, the previously approved Clarris Phegor Obriko profile is restored automatically.
- Future releases reuse the same profile without setup.
- `setup_profile.bat` is now only for editing details.
