# VOCANTA 3.2.0

VOCANTA 3.2 is the controlled application execution release.

## Production behaviour

- Selects one supported Greenhouse application per run.
- Rejects Jobicy and other blocked or marketplace URLs before browser launch.
- Rejects unsupported application platforms before browser launch.
- Closes immediately when active security verification is detected.
- Completes structured fields, uploads tailored documents, handles multi-step forms, and pauses only for genuine personal or AI-restricted responses.
- Marks an application successful only after recognised confirmation evidence.
- Preserves application diagnostics and audit history.
